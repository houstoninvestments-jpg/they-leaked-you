1. Create the YouTube channel with the handle @TheyLeakedYou. Keep a working contact route on its About page for privacy questions and deletion requests. Confirm the channel is the one you intend to use.

2. Create a new Google Cloud project just for They Leaked You. Enable YouTube Data API v3 and YouTube Analytics API. Set up the Google consent screen with the site https://theyleakedyou.pages.dev, privacy page https://theyleakedyou.pages.dev/privacy/ and terms page https://theyleakedyou.pages.dev/terms/. Create a Web application OAuth client. Add exactly https://theyleakedyou.pages.dev/auth/youtube/callback as an authorized redirect URI. Complete any Google verification required for production use; testing-mode access may expire.

3. Add YOUTUBE_CLIENT_ID and YOUTUBE_CLIENT_SECRET to this repository's Actions secrets. Add CLOUDFLARE_API_TOKEN, CLOUDFLARE_ACCOUNT_ID and ANTHROPIC_API_KEY in the provider secret settings. Scope the Cloudflare token to Pages editing in the designated account, not global account access. Do not post secret values in chat or files. Publish only to the Cloudflare Pages project named theyleakedyou. Run the “Set up and deploy They Leaked You” workflow to install the function and its GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, CF_API_TOKEN, CF_ACCOUNT_ID and CF_PROJECT settings. Keep production authorization settings out of preview deployments.

4. Open https://theyleakedyou.pages.dev/auth/youtube. Read and agree to the privacy policy and terms, then authorize with Google. Select @TheyLeakedYou and review Google's permissions. The first connection pins its immutable channel ID; later reconnections must use that same channel. No token needs to be copied. Do not remove YT_PINNED_CHANNEL_ID when resetting a connection.

5. Confirm the authorization page says Connected and the intended channel is pinned. Set the repository variable ENABLE_PUBLICATION to true and keep APPROVE_PUBLIC_UPLOADS false. This starts paid AI calls at the next eligible 8am, 1pm or 6pm Pacific slot and permits a private test upload only after every gate passes. Inspect that upload in YouTube Studio. If Google reports an unverified or testing-only client, finish its required setup before relying on unattended publishing. Set ENABLE_PUBLICATION false again if you want to pause paid runs while reviewing.

6. After the private test is checked, set APPROVE_PUBLIC_UPLOADS to true only when ready for public videos, with ENABLE_PUBLICATION still true. With ENABLE_PUBLICATION false, the schedule stays a no-cost offline preview. Keep weekly signup collection and paid links disabled until separately approved.
