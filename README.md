# They Leaked You

Evidence-first public breach-notice Shorts and static reference site. Built from Congress Receipts commit 14364cbdaa8262c37ecc68eac10fe686d82b640e; read-only Scam-Check-Shorts-channel schedule reference 67a5eb084f99d7106615c658f4b1831361246ec6. No reference repositories are modified.

## Safe default

`npm run dry-run` scouts the checked-in official aggregate sample, creates an explicitly unvalidated offline script, runs deterministic safety checks, synthesizes Kokoro am_michael/en-us/0.95, renders a vertical Remotion preview under 40 seconds, validates text fit and pixel stability, builds the site, logs zero AI cost and runs health checks. It never contacts paid AI APIs or uploads to YouTube. Missing credentials never become fictional model approvals. The daily workflow defaults to this preview mode. Owner-controlled ENABLE_PUBLICATION and APPROVE_PUBLIC_UPLOADS switches separately enable live processing and public visibility; sealed channel identity is verified before any paid AI calls. Live runs persist sanitized ledger/cost records only after scanning.

`npm run typecheck`, `npm test`, `npm run scan` are release gates. `python3 scripts/scan.py --history` additionally checks every commit’s files, message and attribution for secrets. Email addresses remain forbidden in all files and commit messages; normal GitHub author/committer email attribution is permitted with owner approval. No logos or victim-level source records are used. Models retain exact reference IDs claude-fable-5-1 and claude-opus-5-5; unavailable models fail closed, not silently substituted. Live review uses two independent checker calls; both must approve at confidence >=0.99 with no concerns.

## Engine

Official scout → writer → two independent fact checks → Kokoro → Remotion → measured text fit and pixel region checks → gated YouTube upload with containsSyntheticMedia=true → static Cloudflare site → read-only retention analytics → health report. Production entry requires explicit --live, publication flag, configured secrets, a pinned verified channel, and a schedule slot. First uploads are private. No publish automation is active by default. Retention-based hook selection uses actual analytics only after minimum sample thresholds, otherwise it balances exploration without declaring a winner. Raw analytics are fetched anew for recent videos each live run, excluded from artifacts and git, and held only in process memory; learning requires no private storage service.

The title and speech preserve regional count scope. Reported and exposed dates are different fields. SSN/PASSWORDS/EMAIL ONLY badges require supporting categories; unknown is never presented as low risk. Email exclusivity requires explicit evidence. Counts describe the notice's population, not proof the viewer was affected. No unsupported negligence claims.

## Sources

The enabled source is the Washington Attorney General's official open-data aggregate dataset, `https://data.wa.gov/resource/sb4j-ca4h.json`, joined by `id` to category dataset `https://data.wa.gov/resource/padd-mby7.json`. Category rows repeat counts: union categories, never sum counts. Only aggregate whitelisted fields are retained, not raw response bodies or notification-letter attachments. Requests are spaced at least 1.1 seconds. Unknown categories, incomplete evidence and failed checks are skipped. The sample is record 25702, Poppins Payroll Company, reported 2026-09-29, incident start 2026-09-03, 17,954 Washington residents. Being the notifying entity does not establish whose system was compromised.

Source-access and reuse guidance was verified at `https://data.wa.gov/robots.txt` and `https://data.wa.gov/stories/s/Data-wa-gov-Accounts-for-All-Users/sczx-5db5/`. HHS is not enabled: no compatible verified category evidence was established. No HHS facts are fabricated or silently substituted. Website snapshots and sample are preview artifacts, not current breaking news.
